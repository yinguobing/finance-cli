算盘 The Abacus for the Agent Era

智能体时代的个人财务管理工具。像算盘珠子一样精确，像命令行一样高效。 所有数据本地存储，无需网络，完全掌控。

$ curl -sSL https://raw.githubusercontent.com/yinguobing/suanpan/main/install.sh | bash ⎘ 复制
01

特性

本地优先

所有数据存储在本地 SurrealKV 嵌入式数据库，无需网络连接，单文件便于备份。

精确计算

使用 Decimal 类型进行所有金额计算，杜绝浮点数精度问题，分毫不差。

多种交易类型

支持支出、收入、转账、债务变动、债权变动五种交易类型，全面覆盖个人财务场景。

智能查询

模糊搜索、组合筛选、CSV 导出，快速找到任何一笔交易记录。

统计报表

月度收支统计、分类占比、趋势分析、环比同比对比，全面掌握财务状况。

多级分类

灵活的多级分类体系，支持层级汇总。内置标签与账户管理。

数据导入

支持随手记 XLS/XLSX/CSV 格式导入，自动去重，无缝迁移历史数据。

HTML 报表

一键生成结构化 HTML 数据报表，方便分享给智能体进行分析。

Agent 友好

所有输出均可切换为 LLM 友好格式，专为智能体时代的自动化财务管理设计。

04

为什么选择算盘

云端记账工具

  • 数据存储在第三方服务器
  • 需要注册账号和网络连接
  • 隐私取决于服务商政策
  • 功能臃肿，广告干扰
  • API 受限，自动化困难
  • 数据迁移和导出受限

算盘

  • 数据完全在你手中
  • 离线可用，无需注册
  • 开源可审计，GPL-3.0
  • 专注核心功能，简洁高效
  • 为智能体和自动化而生
  • 标准格式，自由导入导出
05

安装

快速安装（推荐）

curl -sSL https://raw.githubusercontent.com/yinguobing/suanpan/main/install.sh | bash

自动检测操作系统和架构，下载对应预编译二进制。

从源码编译

git clone https://github.com/yinguobing/suanpan.git
cd suanpan
cargo build --release
sudo cp target/release/suanpan /usr/local/bin/

需要 Rust 1.82+ 工具链。

🗄 数据存储位置：~/.local/share/suanpan/data.db
